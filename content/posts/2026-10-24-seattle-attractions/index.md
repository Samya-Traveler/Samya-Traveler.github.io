## 🚇 交通：Link 輕軌＋公車

{{< figure src="gallery/01-link.jpg" caption="左：ORCA 售票機；右：Link 輕軌" align="center" >}}

西雅圖市區用**大眾運輸**就很方便，不用租車：

| 交通 | 說明 |
|---|---|
| 🚈 Link 輕軌 | 機場 ⇄ 市中心 ⇄ 華盛頓大學<br>東線可以到 Redmond（微軟） |
| 🚌 公車 | King County Metro，路線多 |
| 🚝 單軌電車 | Westlake ⇄ 西雅圖中心（太空針塔）<br>單程 **USD 4** |
| 💳 付款 | 買一張 **ORCA 卡**，或手機 Transit GO 購票 |

## 🗓️ 10/19：派克市場一帶

### 錘人雕像＋口香糖牆

{{< figure src="gallery/02-hammering-gum.jpg" caption="左：西雅圖美術館前的錘人雕像 Hammering Man；右：口香糖牆" align="center" >}}

從西雅圖美術館前的**錘人雕像**往海邊走，就會到派克市場。
市場下方的 Post Alley 有一整面**口香糖牆（Gum Wall）**，五顏六色黏滿牆壁，有點噁心但很壯觀 😂

### 派克市場 Pike Place Market

{{< figure src="gallery/03-pike-place.jpg" caption="左：派克市場；右：市場外牆上的大豬" align="center" >}}

1907 年開幕、美國最老的農夫市場之一，有魚攤、花攤、蔬果和各種小店。
**「PUBLIC MARKET」紅色招牌**和市場的**豬**（市場吉祥物）是必拍。

| 項目 | 內容 |
|---|---|
| 📍 地址 | 85 Pike St, Seattle<br>[Google 地圖](https://www.google.com/maps/search/?api=1&query=Pike+Place+Market) |
| 🎫 費用 | 免費 |
| 🕘 時間 | 大多店家 9:00–18:00 左右 |
{.trip-facts}

### 星巴克創始店 Original Starbucks

{{< figure src="gallery/04-starbucks.jpg" caption="左：創始店的櫥窗；右：棕色的舊版雙尾美人魚 Logo" align="center" >}}

派克市場對面的**第一家星巴克（1912 Pike Place）**，招牌是**棕色的舊版雙尾美人魚**。
店很小、排隊的人很多，我 11:20 左右到就排了很長的隊。

{{< figure src="gallery/05-starbucks-coffee.jpg" caption="左：在派克市場喝冰拿鐵；右：Pike Place 限定咖啡豆" align="center" >}}

> [!TIP] 不想排隊
> 創始店主要是**拍照朝聖**，想好好坐下喝咖啡，可以去附近其他分店。下午人通常比較少。

### Overlook Walk＋西雅圖摩天輪

{{< figure src="gallery/06-overlook-wheel.jpg" caption="左：從 Overlook Walk 看海；右：西雅圖摩天輪 Seattle Great Wheel" align="center" >}}

**Overlook Walk** 是 2024 年新開的空中步道，從派克市場直接走下到海濱，一路可以看海、看摩天輪。
走到海濱就是 **Pier 57 的摩天輪**，旁邊的 **Ye Olde Curiosity Shop** 是百年老店，裡面擺滿奇怪的收藏，很好逛。

{{< figure src="gallery/07-curiosity-shop.jpg" caption="Ye Olde Curiosity Shop 的人偶收藏" align="center" >}}

### 西雅圖水族館 Seattle Aquarium

{{< figure src="gallery/08-aquarium.jpg" caption="左：新館 Ocean Pavilion；右：水母" align="center" >}}

2024 年開幕的新館 **Ocean Pavilion** 有超大的珊瑚礁水族箱，舊館有水母、海豹、海獺。
我逛了大約 **2 小時**，下雨天來剛好。

{{< figure src="gallery/09-aquarium2.jpg" caption="左：海獅；右：Ocean Pavilion 的大水族箱" align="center" >}}

| 項目 | 內容 |
|---|---|
| 📍 地址 | 1483 Alaskan Way（Pier 59）<br>[Google 地圖](https://www.google.com/maps/search/?api=1&query=Seattle+Aquarium) |
| 🕘 時間 | 9:30–18:00（17:00 最後入場） |
| 🎫 門票 | 依日期浮動，建議官網先買 |
| 🌐 官網 | [seattleaquarium.org](https://www.seattleaquarium.org/) |
{.trip-facts}

### Sky View 觀景台（Columbia Center）

{{< figure src="gallery/10-sky-view.jpg" caption="左：從觀景台看到的彩虹；右：普吉特灣的夕陽" align="center" >}}

**西雅圖最高的觀景台**（73 樓），比太空針塔還高，而且**可以把太空針塔一起拍進去**。
我傍晚去，先看到**彩虹**，再看到整片夕陽，是這趟西雅圖最驚喜的一刻。

{{< figure src="gallery/11-sky-view2.jpg" caption="左：從上面俯瞰太空針塔；右：西雅圖市中心" align="center" >}}

| 項目 | 內容 |
|---|---|
| 📍 地址 | 700 4th Ave, Seattle<br>[Google 地圖](https://www.google.com/maps/search/?api=1&query=Sky+View+Observatory) |
| 🎫 門票 | 大人約 **USD 25～34**（依購買管道） |
| 💡 推薦 | **日落前 30 分鐘**上去 |
{.trip-facts}

## 🗓️ 10/20：微軟園區（Redmond）

{{< figure src="gallery/12-microsoft.jpg" caption="左：Microsoft 招牌；右：園區內的休息區" align="center" >}}

從市區搭 **Link 東線**就能到 Redmond 的微軟總部。
我們在 Microsoft 招牌前拍照、逛了 **Microsoft Store**（有微軟限定的周邊）和介紹公司歷史的展區，中午在園區的餐廳吃了 poke bowl。

{{< figure src="gallery/13-microsoft2.jpg" caption="左：微軟歷史展區的早期電腦；右：園區餐廳的 poke bowl" align="center" >}}

> [!WARNING] 參觀前先確認
> 微軟原本的 **Visitor Center（Building 92）已於 2026 年初關閉**，園區內很多地方需要員工帶才能進去。
> 想去請先查清楚目前開放的區域，**Microsoft Store 仍有營業**。

晚上去 **Costco** 買伴手禮，再到 **KIZUKI Ramen** 吃拉麵。

## 🗓️ 10/21：華盛頓大學＋太空針塔

### 華盛頓大學 University of Washington

{{< figure src="gallery/14-uw.jpg" caption="左：紅場 Red Square 和蘇扎洛圖書館；右：圖書館裡的雕像" align="center" >}}

搭 Link 到 **U District / University of Washington 站**就到。
一定要去**蘇扎洛圖書館（Suzzallo Library）**的閱覽室，**挑高的哥德式拱頂、長桌和吊燈**，就像哈利波特的霍格華茲。

{{< figure src="gallery/15-suzzallo.jpg" caption="蘇扎洛圖書館的閱覽室 Reading Room" align="center" >}}

> [!TIP] 參觀禮儀
> 閱覽室是學生讀書的地方，**要保持安靜**、拍照不開閃光燈。

接著走到 **Drumheller 噴泉**，天氣好的時候可以看到遠方的**雷尼爾山（Mount Rainier）**。
10 月的校園**楓葉轉紅**，草地上還有很多加拿大雁，很適合散步。

{{< figure src="gallery/16-uw-fountain.jpg" caption="左：Drumheller 噴泉；右：秋天的校園和加拿大雁" align="center" >}}

### 單軌電車＋太空針塔 Space Needle

{{< figure src="gallery/17-space-needle.jpg" caption="左：單軌電車 Monorail；右：太空針塔" align="center" >}}

從 Westlake 站搭 **1962 年世博會留下來的單軌電車**，2 分鐘就到西雅圖中心。
**太空針塔**有玻璃地板和戶外觀景台，傍晚上去可以一次看到**市中心、雷尼爾山和夕陽**。

{{< figure src="gallery/18-space-needle-view.jpg" caption="左：遠方的雷尼爾山和市中心；右：普吉特灣的夕陽" align="center" >}}

| 項目 | 內容 |
|---|---|
| 📍 地址 | 400 Broad St, Seattle<br>[Google 地圖](https://www.google.com/maps/search/?api=1&query=Space+Needle) |
| 🎫 門票 | 依時段浮動，**日落時段較貴**<br>可買和 Chihuly 玻璃美術館的套票 |
| 🌐 官網 | [spaceneedle.com](https://www.spaceneedle.com/) |
{.trip-facts}

> [!TIP] Sky View 還是太空針塔？
> - **Sky View**：更高、比較便宜、能拍到太空針塔
> - **太空針塔**：西雅圖地標、有玻璃地板，體驗比較特別
>
> 兩個我都去了，**時間只夠一個的話，我推 Sky View**。

## 🗓️ 10/22：雕塑公園＋亞馬遜球體

### 奧林匹克雕塑公園 Olympic Sculpture Park

{{< figure src="gallery/19-sculpture-spheres.jpg" caption="左：雕塑公園的紅色大雕塑 Eagle；右：亞馬遜球體 The Spheres" align="center" >}}

西雅圖美術館的**免費戶外雕塑公園**，就在海邊，最有名的是紅色的大型雕塑 **Eagle**。

### 亞馬遜球體 Amazon Spheres

亞馬遜總部的**三顆玻璃球溫室**，裡面種了上萬株植物。球體內部主要給員工使用，一般遊客可以在外面拍照，或參觀一樓的展覽 **Understory**。

旁邊的 **Banana Stand** 會**免費發香蕉**，附近還有 **Amazon Go** 無人商店，拿了東西直接走出去就自動結帳。

{{< figure src="gallery/20-amazon.jpg" caption="左：免費的香蕉；右：Amazon Go 無人商店" align="center" >}}

### T-Mobile Park（水手隊主場）

{{< figure src="gallery/21-tmobile.jpg" caption="左：T-Mobile Park；右：水手隊商店的周邊" align="center" >}}

西雅圖水手隊的主場，非球賽日也可以逛**球隊商店**，買棒球帽和周邊。逛完就搭 Link 到機場。

## 🍽️ 吃什麼

{{< figure src="gallery/22-food.jpg" caption="左：Wendy's；右：KIZUKI Ramen 的拉麵" align="center" >}}

{{< figure src="gallery/23-food2.jpg" caption="左：華盛頓大學附近的漢堡；右：最後一晚的晚餐" align="center" >}}

西雅圖外食也不便宜，一餐 **USD 20 起＋小費（18% 以上）**。
我們吃了 **Wendy's**、**KIZUKI Ramen** 等，晚上也常去 **Costco、Trader Joe's** 買東西回飯店吃。

## 出發前檢查清單

- [ ] 準備 **ORCA 卡**或下載 **Transit GO**，Link＋公車很方便
- [ ] **太空針塔、水族館**先在官網買票
- [ ] Sky View／太空針塔查好**日落時間**
- [ ] 西雅圖常下雨，帶**防水外套**
- [ ] 小費 **18% 以上**
